 Propósito
  Site estático desenvolvido para o Trabalho Avaliativo 01 de Desenvolvimento Web I.

 Tema
  O site apresenta informações introdutórias sobre Outer Wilds, um jogo investigativo e de mundo aberto, sua exploração espacial, alguns planetas e a civilização Nomai.

 Tecnologias utilizadas serão o:
  HTML, CSS, Git, GitHub e GitHub Pages.

 Estrutura
- `index.html` — página inicial
- `historia.html` — informações sobre o jogo
- `planetas.html` — locais do sistema solar
- `nomai.html` — informações sobre os Nomai
- `sobre.html` — informações do trabalho
- `css/style.css` — folha de estilos

Não será utilizado JavaScript, framework ou tema pronto em nenhum momento do trabalho.
