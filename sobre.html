Sobre o projeto

Este site foi desenvolvido para o Trabalho Avaliativo 01 da disciplina de Desenvolvimento Web I, do curso Técnico Integrado em Informática para Internet.

Tecnologias utilizadas

  • HTML para a estrutura das páginas
  • CSS para o visual e layout
  • Git para versionamento
  • GitHub para armazenar o projeto
  • GitHub Pages para publicar o site

Por que Outer Wilds?

Escolhi o tema por ser um jogo que marcou muito minha vida e ser meu jogo favorito, ele passou de ser uma experiência e virou parte de mim.
